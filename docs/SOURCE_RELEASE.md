# Source release boundaries

This repository contains authored FM5 compatibility adapters, the adapted GPL builder UI, tests, numeric/tyre icons, and guard/patch metadata. It contains no prepared engine binary, game/SDK DLL, game image, shader payload, archive, save, private log, local Python installation or package cache.

A complete native runtime cannot currently be reproduced from only this checkout: separately obtained engine/SDK inputs and user-local generated shader/guard inputs are required. The README and BUILDING guide state this limitation. The WPF interface can be compiled and tested independently.

Only the authored Hub and numeric 5 icons are included as raster/icon assets. Gameplay screenshots and the game-derived pre-game background are omitted. Existing private development and other game work are not part of this repository.
